Set up the client

This setup fragment reads credentials from the environment. Use the API operation reference to supply input for each call.

import os
from dingconnect_sdk import DingconnectSDK

client = DingconnectSDK({"apikey": os.environ.get("DINGCONNECT_APIKEY")})
