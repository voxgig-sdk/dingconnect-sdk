Tools

dingconnect_list

List records for an entity.

{
  "type": "object",
  "required": [
    "entity"
  ],
  "properties": {
    "entity": {
      "type": "string",
      "description": "account_lookup | balance | cancel_transfer | country | currency | error_code_description | estimate_price | list_transfer_record | lookup_bill | product | product_description | promotion | promotion_description | provider | provider_status | region | send_transfer"
    },
    "query": {
      "type": "object",
      "description": "Optional match fields for the selected entity."
    }
  }
}

Supported entities: account_lookup, balance, country, currency, error_code_description, product, product_description, promotion, promotion_description, provider, provider_status, region.

dingconnect_load

Load one record for an entity.

{
  "type": "object",
  "required": [
    "entity"
  ],
  "properties": {
    "entity": {
      "type": "string",
      "description": "account_lookup | balance | cancel_transfer | country | currency | error_code_description | estimate_price | list_transfer_record | lookup_bill | product | product_description | promotion | promotion_description | provider | provider_status | region | send_transfer"
    },
    "query": {
      "type": "object",
      "description": "Optional match fields for the selected entity."
    }
  }
}

This tool is registered, but no active entity supports load.
